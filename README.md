# EasyBook

EasyBook is a Smart Resource Booking Platform designed to help institutions manage shared resources such as laboratories, seminar halls, equipment, and sports facilities without scheduling conflicts.

## Core Features

- User authentication
- Resource catalogue
- Resource booking
- Conflict detection
- Booking history
- Booking cancellation
- Admin resource management
- Usage analytics

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- Firebase Authentication
- Cloud Firestore
- Firebase Hosting
